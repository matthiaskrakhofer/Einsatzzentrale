# Einsatzleitungszentrale

Kleine statische Webseite mit freischaltbaren Aufgaben fuer eine Rettungsmission nach einem Flugzeugabsturz.

## Kostenlos online stellen

### Option 1: GitHub Pages

1. Erstelle ein neues Repository auf GitHub, zum Beispiel `einsatzleitungszentrale`.
2. Lade diese Dateien in das Repository hoch:
   - `index.html`
   - `styles.css`
   - `app.js`
3. Oeffne auf GitHub im Repository `Settings` > `Pages`.
4. Waehle bei der Veroeffentlichung `Deploy from a branch`.
5. Waehle Branch `main` und den Ordner `/ (root)`.
6. Nach kurzer Zeit ist die Seite unter einer GitHub-URL erreichbar.

Bei einem Projektrepository ist die Adresse normalerweise:

`https://DEIN-NAME.github.io/REPOSITORY-NAME/`

### Option 2: Netlify

1. Gehe auf Netlify und melde dich kostenlos an.
2. Ziehe den Ordner `einsatzleitungszentrale` direkt in das Deploy-Feld.
3. Netlify veroeffentlicht die Seite automatisch und gibt dir sofort eine URL.

## Lokal starten

Einfach `index.html` im Browser oeffnen.
